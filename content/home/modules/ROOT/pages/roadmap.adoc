= Vidocq ecosystem consolidated roadmap
:description: Per-module status and upcoming milestones.

[.lead]
This page aggregates the progress of all twenty modules — twelve Jakarta EE bricks (including the Vidocq Runtime orchestrator) plus eight MicroProfile implementations. Each section links to the module's documentation for details. The suite is released as `0.2.x` on Maven Central — an alpha, APIs may still change.

== Detailed status by module

=== Chappe — HTTP transport

* **Done**: HTTP/1.1 and HTTP/2 conformant to RFC 9110/9112/9113, virtual threads, zero dependency.
* **In progress**: HTTP/3 / QUIC, WebSocket (RFC 6455), TLS hardening.
* **Coming up**: MicroProfile Telemetry integration on the transport side.
* Details: xref:chappe::index.adoc[Chappe].

=== Vauban — CDI 4.1 Lite

* **Done**: build-time injection graph resolution, Maven plugin, JUnit integration, Class-File API + APT generation, official CDI 4.1 Lite TCK **774/774**.
* **In progress**: `ScopedValue` propagation for scoped contexts, class-loading layers for dev mode.
* **Coming up**: Full profile (beyond Lite).
* Details: xref:vauban::index.adoc[Vauban].

=== Champollion — JSON-P / JSON-B

* **Done**: JSON-P 2.1 (178/179 PASS, 99.4%), JSON-B 3.0 bindings generated by APT.
* **In progress**: full JSON-B 3.0 TCK baseline, streaming performance hardening.
* **Coming up**: JSON Patch profile, advanced JSON Pointer.
* Details: xref:champollion::index.adoc[Champollion].

=== Foy — Servlet 6.1

* **Done**: ~90% of the official Jakarta Servlet 6.1 TCK, Chappe transport integration, Vauban CDI integration.
* **In progress**: 100% TCK coverage, WebSocket via Chappe, async hardening.
* **Coming up**: Servlet 7 once the spec is published.
* Details: xref:foy::index.adoc[Foy].

=== Cassini — Jakarta REST 4.0

* **Done**: 2538 applicable REST 4.0 TCK tests green (100%), SSE real-time streaming, Chappe transport integration, Champollion entity providers, optional Vauban CDI.
* **In progress**: MicroProfile (Config, Health) integration hardening, advanced filters and interceptors.
* **Coming up**: MicroProfile JWT `@RolesAllowed` integration on Cassini (via xref:cervantes::index.adoc[Cervantes]).
* Details: xref:cassini::index.adoc[Cassini].

=== Mansart — Jakarta Data + Transactions

* **Done**: Jakarta Data 1.0 — official TCK **74/74**, virtual-thread-native JDBC pool, named datasources (`dataStore` routing), Jakarta Transactions 2.0 transaction manager, `@Transactional` via Vauban.
* **In progress (M6c)**: full Jakarta Transactions 2.0 TCK suite.
* **Moved**: Jakarta Persistence 3.2 left Mansart for xref:noether::index.adoc[Noether] on 2026-10-11. `mansart-jakarta-data` already covers everyday needs in Vidocq.
* Details: xref:mansart::index.adoc[Mansart].

=== Erasmus — Jakarta Validation 3.1

* **Done**: bootstrap (`Validation.buildDefaultValidatorFactory()`), the 21 built-in constraints, custom and composed constraints, message interpolation (EL subset, EN/FR bundles).
* **In progress**: cascaded validation and groups, `ValueExtractor` SPI, executable validation.
* **Coming up**: APT static codegen, CDI (Vauban) and Jakarta REST (Cassini) integration, official TCK, first release.
* Details: xref:erasmus::index.adoc[Erasmus].

=== Noether — Jakarta Persistence 3.2

* **In progress**: Jakarta Persistence 3.2 with generated entity access and virtual-thread JDBC execution, on Mansart's pool and transactions; Vidocq Runtime extension.
* Details: xref:noether::index.adoc[Noether].

=== Peano — Jakarta Expression Language 6.0

* **Done**: grammar, operators, coercions, functions, method expressions, lambdas and collection operations, build-time accessors and compiled expressions; official EL 6.0.1 TCK **361/361**.
* **Coming up**: first release.
* Details: xref:peano::index.adoc[Peano].

=== Ibarra — Jakarta Pages 4.0

* **Done**: runtime and parser, Maven packaging (build-time precompilation), Foy HTTP binding, TLD listeners, compiled EL on Peano.
* **In progress**: build-time page generation (I3–I6), full tag semantics.
* **Coming up**: certification, Vidocq Runtime extension.
* Details: xref:ibarra::index.adoc[Ibarra].

=== Tassis — Jakarta Messaging 3.1

* **Done**: classic, simplified and legacy domain-specific APIs on an in-memory broker of its own; the broker opened to the network over AMQP 1.0, with TLS, for the Tassis client and for any other AMQP 1.0 client; connection pool; `JMSContext` injection on Vauban; official Messaging 3.1 TCK **903/903** of the tests that apply to a Java SE provider, in the JVM and through the network.
* **Coming up**: XA and JTA, first release.
* Details: xref:tassis::index.adoc[Tassis].

=== MicroProfile layer

Eight independent MicroProfile implementations, each wired into Vidocq Runtime through the extension SPI and, where relevant, exposed over Cassini.

The assembled runtime passes **1868 official MicroProfile 7.1 TCK tests** across these eight specs (see the xref:vidocq::tck.adoc[runtime TCK page]).

* xref:ravel::index.adoc[Ravel] — MicroProfile Config 3.1. TCK green (349 tests on the assembled runtime).
* xref:knock::index.adoc[Knock] — MicroProfile Health 4.0. TCK green.
* xref:dirac::index.adoc[Dirac] — MicroProfile Metrics 5.1. TCK green.
* xref:heisenberg::index.adoc[Heisenberg] — MicroProfile Fault Tolerance 4.1. TCK green (463 tests).
* xref:cervantes::index.adoc[Cervantes] — MicroProfile JWT 2.1. TCK 206/206; `@RolesAllowed` wired into Cassini.
* xref:cyrano::index.adoc[Cyrano] — MicroProfile Rest Client 4.0. TCK 235/235 (SSL and SSE included).
* xref:humboldt::index.adoc[Humboldt] — MicroProfile Telemetry 2.1. Implemented (trace/metric/log SDKs, OTLP-HTTP exporter, W3C propagation); gRPC export post-MVP.
* xref:grimm::index.adoc[Grimm] — MicroProfile OpenAPI 4.1. TCK green (344 tests).

=== Vidocq Runtime — orchestrator

* **Done**: bootstrap, lifecycle, BuildStep / BuildItem / Recorder SPI, Mansart H2 + transactions extensions, MicroProfile extension wiring (Config, Health, Metrics, Fault Tolerance, JWT, Rest Client, Telemetry, OpenAPI), Maven plugin (jlink / jpackage / Docker).
* **In progress**: cross-cutting MicroProfile integration hardening, packaging.
* **Coming up**: GraalVM `native-image` and Project Leyden CDS proof-of-concept.
* Details: xref:vidocq::index.adoc[Vidocq Runtime].

== Track progress

Reproducible bugs and performance numbers are recorded at the root of each repo:

* `BUG.md` — reproducible bugs, hypotheses, status.
* `BENCH.md` — JMH/wrk/comparative runs, deltas vs previous run.

Official TCKs (Cassini, Foy, Champollion, Mansart, and the MicroProfile modules) are executed via the `run-official-tck-*.sh` scripts of the relevant sub-project.
